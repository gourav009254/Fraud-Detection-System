# Fraud Detection System

A Machine Learning-based web application that predicts whether a financial transaction is **Genuine or Fraudulent**.

## Features

- Transaction fraud prediction
- Transaction type and balance inputs
- Automatic feature calculation
- Logistic Regression model
- Interactive Streamlit interface

## Tech Stack

- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit

## Model Performance

- Accuracy: 95.24%
- Fraud Recall: 98%
- ROC-AUC: 99.41%

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
